## Анализ результатов
1. **Сравнение моделей:**
   - U-Net показал более высокую тестовую точность и F1 Score по сравнению с SegFormer. Это может быть связано с тем, что U-Net лучше подходит для задач семантической сегментации благодаря своей архитектуре, которая эффективно обрабатывает пространственные данные.
   - SegFormer, хотя и является более современной моделью, может требовать большего объема данных для достижения аналогичных результатов.

2. **Время обучения:**
   - SegFormer требует меньше времени на каждую эпоху по сравнению с U-Net, что может быть связано с оптимизацией его архитектуры. Однако, несмотря на это, U-Net демонстрирует более высокую производительность по метрикам.
   - U-net: Time: 116.68s
   - SegFormer: Time: 111.60s

3. **Графики:**
   - Графики, отображающие метрики по эпохам, показывают, что U-Net имеет более стабильный и предсказуемый рост точности и F1 Score по сравнению с SegFormer.
